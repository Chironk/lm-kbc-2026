# Preserved official-test submissions

This directory stores immutable submission artifacts separately from ignored
experiment run directories.

`heterogeneous_final_strict_proof_20260803_v1_test.zip` is the exact archive
submitted for the earlier official-test result reported as macro-F1 0.4845.
Its byte and member hashes are pinned in `heterogeneous_final_strict_proof_20260803_v1_test.manifest.json`.
The manifest also preserves the owner-supplied Codabench precision, recall,
and F1 breakdown used in the final paper's official-test table.

The score is recorded from the Codabench result supplied by the project owner;
test labels are not present locally, so the repository does not claim to
recompute that score.
