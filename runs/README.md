# Local run outputs

This directory is the default destination for generated task plans, model
responses, graphs, logs, predictions, and submission archives. Everything
under it is ignored by Git except this file.

Do not treat a local run as a release artifact. The exact official submission
reported in the paper is preserved separately under
`submissions/official_test/`, with its archive and member hashes recorded in a
manifest. Compact, reviewed experiment outcomes belong under
`results/research_summaries/`.
